Политика конфиденциальности игры «Ханга»

Дата последнего обновления: 15 сентября 2026 года

Эта политика описывает, какие данные обрабатывает мобильная игра «Ханга» (идентификатор приложения ru.hanga.game, далее — «Игра») и зачем. Устанавливая Игру, вы соглашаетесь с этой политикой.

1. Кто обрабатывает данные

Разработчик Игры: Колемагин Дмитрий. Связаться: kolemagin.dmitriy@yandex.ru

Разработчик не создаёт учётных записей и не собирает имя, адрес, телефон, электронную почту, платёжные реквизиты, данные о местоположении, контакты, фотографии, микрофон или камеру. Игра не запрашивает соответствующих разрешений: в списке разрешений Игры только доступ в интернет, проверка наличия сети и рекламный идентификатор.

2. Что хранится на вашем устройстве

Прогресс по кроссвордам (отметки на поле, время решения, число использованных подсказок) и настройки хранятся локально на вашем устройстве. Разработчик не имеет к ним доступа.

Если на устройстве включено резервное копирование Android, система может сохранить прогресс и настройки Игры в резервной копии вашего аккаунта Google и перенести их на новый телефон. Это делает сама система Android; разработчик к этой копии доступа не имеет. Данные для входа через Яндекс ID в резервную копию не попадают.

Локальные данные удаляются вместе с Игрой.

3. Перенос прогресса — по желанию

Игра полностью работает без входа и без интернета. Чтобы перенести прогресс на другой телефон, есть два способа, оба включаются только вами.

3.1. Вход через Яндекс ID

Окно входа — официальное, от Яндекса. Игра просит у Яндекса только одно право: доступ к папке приложения на вашем Яндекс Диске — ни имени, ни почты, ни других файлов Диска Игра не получает.

В этой папке хранится один файл, progress.json, — тот же прогресс, что и на телефоне (отметки, время, подсказки). Файл лежит на вашем Диске: разработчик к нему доступа не имеет, собственного сервера у Игры нет.

Ключ доступа хранится на устройстве в зашифрованном виде и уходит только на сервер API Яндекс Диска.

Удалить данные можно в любой момент:

  • файл на Диске — «Настройки» → «Прогресс» → «Удалить данные с Диска»;
  • доступ Игры к Диску — на странице доступов Яндекс ID: https://id.yandex.ru/personal/data-access

Политика Яндекса: https://yandex.ru/legal/confidential/

3.2. Файл прогресса

Прогресс можно сохранить в файл и открыть его на другом телефоне. Куда сохранить файл, выбираете вы в системном окне Android; Игра видит только этот файл и никуда его не отправляет.

4. Реклама — Яндекс Реклама (Yandex Mobile Ads)

Игра бесплатна и живёт за счёт рекламы, поэтому в неё встроен рекламный SDK Яндекса. Он обрабатывает данные самостоятельно, как отдельный оператор, и разработчику Игры эти данные в виде, позволяющем идентифицировать человека, не передаются.

Где показывается реклама:

  • ролик за подсказки — только когда вы сами его попросили, после того как бесплатные подсказки кончились;
  • межстраничная реклама — только после решённого кроссворда, когда вы уходите с готовой картинки: не раньше четвёртого решённого, не после коротких кроссвордов и не чаще раза в десять минут игры.

Во время решения реклама не показывается. Баннеров нет.

Обрабатывает: рекламный идентификатор устройства (Google Advertising ID), IP-адрес, модель устройства, версию ОС, язык, приблизительный регион по IP, сведения о показах и нажатиях по рекламе.

Цель: подбор и показ рекламы, подсчёт показов, борьба с мошенническими показами.

Политика Яндекса: https://yandex.ru/legal/confidential/

Других сторонних SDK в Игре нет: ни аналитики, ни покупок, ни сервисов Google Play.

5. Дети

Игра не адресована детям младше 13 лет и не собирает данные о них осознанно. В Игре нет чата, обмена сообщениями и любого общения между игроками.

6. Как отказаться от обработки данных

  • Персонализированная реклама. Android: «Настройки» → «Google» → «Реклама» → удалить рекламный идентификатор или включить отказ от персонализации. Реклама останется, но перестанет подбираться под вас.
  • Прогресс на Яндекс Диске. Удалите его из Игры и снимите доступ на странице Яндекс ID (раздел 3.1).
  • Локальные данные. Удалите Игру — вместе с ней удаляются прогресс и настройки.
  • Запрос на удаление данных. Напишите на kolemagin.dmitriy@yandex.ru, указав рекламный идентификатор устройства. Разработчик передаст запрос рекламной сети.

7. Передача данных третьим лицам

Разработчик не продаёт и не передаёт данные третьим лицам, кроме сервисов, названных выше. Данные могут быть раскрыты по обоснованному требованию государственных органов в порядке, установленном законом.

8. Хранение и безопасность

Разработчик не хранит пользовательские данные на своих серверах — серверов у Игры нет. Сроки хранения данных на стороне Яндекса и Google определяются их собственными политиками. Связь с сервисами Яндекса идёт по HTTPS.

9. Изменения политики

Политика может обновляться. Актуальная версия всегда доступна по этой ссылке, дата обновления указана в начале документа. Существенные изменения будут отражены в описании обновления Игры.
